# Nepali Wedding Invitation — Video Production Brief

**Target:** 35 seconds, 16:9, 1080p  
**Visual direction:** Editorial Swiss / architecture-inspired portfolio design: warm ivory canvas, high-contrast black serif titles, fine hairline rules, small vermilion monospaced labels, restrained grid layouts, compact project metadata. Use real repository screenshots and screen recordings; no generic robot imagery, fake dashboards, fabricated metrics or invented testimonials.

## Creative direction

A tasteful walkthrough of the existing invitation page. Show the entry interaction, Nepali typography, approved photos and the event details. Use only images and music that are cleared for publication; do not alter names, dates or family text.

## Shot list

0–5s: quiet maroon-and-ivory title. 5–13s: invitation entry transition. 13–25s: scroll through the real invitation, Devanagari text and approved photos. 25–31s: optional audio control. 31–35s: project credit.

## Voiceover draft

A responsive Nepali wedding invitation experience with Devanagari typography, editorial pacing and traditional visual details.

## Production checklist

- Capture the current app from the repository; do not invent screens.
- Blur or exclude private data, credentials, tokens and personal information.
- Use only assets the repository owner has permission to publish.
- Verify any prediction, API response or feature shown in the edit.
- End with the repository name and a short GitHub URL.
- Export MP4 (H.264), 1920×1080, 24 or 30 fps, with readable captions.
