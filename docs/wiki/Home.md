# Nepali Wedding Invitation — Project Wiki

Responsive Nepali wedding invitation page with Devanagari typography, invitation entry interaction, image sections and optional background audio.

## Quick start

Open `index.html` in a modern browser. Keep image and audio assets at their expected relative paths. Browser autoplay policies may require visitors to start audio manually.
